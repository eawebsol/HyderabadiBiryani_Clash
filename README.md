# Biryani Clash: Hyderabad Edition 🍗🔥

> **Solve the 45-minute WhatsApp group chat argument over where to eat authentic Hyderabadi biryani right now.**

An interactive, high-vibe micro-app built with **React 18**, **Tailwind CSS**, and **Canvas Confetti**, packed with authentic local spots, real-time voting, spice tolerance filters, random toss decider, and authentic Hyderabadi Dakhni street slang error feedback.

---

## 🌟 Key Features

### 1. 🍛 Secret Local Gems Dataset (Real Spots, Zero Paid Influencer Hype)
Pre-seeded with iconic, hyper-specific Hyderabadi joints:
- **Hotel Sohail (Malakpet Gali)** — *Late-night Kaliyan & Dum Biryani* | Spice: Medium | Parking: Road pe challan pakka
- **Meridian Restaurant (Panjagutta)** — *Double Masala Mutton + Extra Raita* | Spice: Spicy | Parking: Basement chaos
- **Cafe Bahar (Basheerbagh)** — *Bahar Special Zafrani Mutton + Mirchi ka Salan* | Spice: Spicy | Parking: Side gali adjustment
- **Chicha's (Lakdikapul)** — *Talawa Gosht + Biryani Rice Combo* | Spice: Spicy | Parking: Auto bhai help
- **Hotel Shadab (Ghansi Bazaar)** — *Zafrani Mutton Biryani + Paye Soup* | Spice: Medium | Parking: Bike only
- **Grand Hotel (Abids Est. 1935)** — *Vintage Dum Biryani with Bun Maska & Kadak Chai* | Spice: Mild | Parking: Late night roadside
- **Rumaan Restaurant (Tolichowki)** — *Pocket-rocket Masala Beef Biryani* | Spice: Spicy | Parking: Basement slot

### 2. 🗳️ Live Group Voting & Leaderboard
- Real-time upvoting (+1 vote) with live flame reaction animations.
- Dynamic **#1 Group Winner Banner** with lead margin and 1-click WhatsApp plan locking.
- Duplicate vote prevention with authentic street-slang error feedback.
- Session persistence via `localStorage`.

### 3. 🌶️ Spice Level & Distance Filters
- **Spice Level Filter**: Instant filtering by **Mild** (🟢 Mellow Irani), **Medium** (🟡 Classic Dum), and **Spicy** (🔴 Tezz / Double Masala).
- **Distance Slider**: Interactive range slider (2 km to 15 km) with street warnings when dragging too far out.
- **AI-Blind Spots Toggle**: Show only hidden gali spots.

### 4. 🎯 "Toss Karo" Random Decider
- Resolves group chat deadlock with an animated random picker.
- Strict filter adherence (respects distance, hidden gems, and active spice level filter).
- Celebratory confetti burst and synthesized Web Audio sound effects.

### 5. 🗣️ Dakhni / Hyderabadi Street Slang Engine
Replaces generic alerts with authentic street dialect:
- *Already Voted*: *"🛑 Kya miyan, ek hi dukan ko do do baar vote daalre? Chindi chorgiri nako karo!"*

- *Meridian Protocol*: *"🥛 Khabardaar! Meridian me extra raita mangte waqt aawaz dheemi rakho... purana itihaas hai!"*
- *Distance Alert*: *"✈️ Arey bhai, Shamshabad flight pakad ke jaate kya biryani khane? Aas-paas ka filter lagao!"*

## 🚀 How to Run Locally

### Option A: Open Directly in Browser (Zero Install)
Double-click `index.html` or open it in any web browser. It runs completely standalone with React 18, Babel standalone, and Tailwind CSS CDN.

### Option B: Run via Vite Dev Server
```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```
Open `http://localhost:3000` in your browser.
